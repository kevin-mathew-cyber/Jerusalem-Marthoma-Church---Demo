# Church website demo

Upload index.html, the images folder, and .nojekyll to the root of your GitHub repository. Do not upload the outer github-site folder or the ZIP itself.

The index.html file must sit beside the images folder. Replace the previous index.html.

For small text changes, open index.html on GitHub, choose Edit, search for the text you want to change, then commit your changes. Keep the image paths intact.

GitHub Pages: deploy from main, / (root).
